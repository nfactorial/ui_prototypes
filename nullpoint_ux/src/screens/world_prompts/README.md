# In-world prompts (grey-box)

**Serves:** `flow.md` F2: the game launches into the world and teaches through prompts.

- **Onboarding tip:** "Your computer, [C]". Shows until the computer has been opened once
  (`game.computerSeen`).
- **Key hints:** [C] Computer, [Esc] Menu, top-right, always on.
- Interaction prompts ("[E] Force hatch") are on the boarding HUD.
